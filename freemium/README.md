# Offre Freemium

- `index.php` est le point d’entrée de l’offre Freemium.
- `FreemiumController.php` orchestre la page; `model/freemium.php` lit les données.
- La vue correspondante est `view/freemium.php` lorsqu’elle est présente.

## Comprendre `self::`

Voir le fichier `SELF_EXPLANATION.md` à la racine du projet pour une explication simple.
