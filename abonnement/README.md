# Abonnements

`controller/AbonnementController.php` relie le catalogue et les écrans de gestion aux modèles. `model/abonnement.php` fournit le CRUD partagé; `model/ContratAbonnement.php` gère les contrats associés aux souscriptions.

Les vues sont dans `view/`; `catalogue.php` et `index.php` conservent les routes existantes.
